# PQSH

PQSH is an operating system scheduler originally designed as a project for my Operating Systems course. Its main purpose is to create a multi-queue scheduler with the capability of employing different scheduling policies, such as round-robin and FIFO (first-in, first-out), multi-core concurrency, and measuring different scheduling metrics, such as average turnaround time and response time. This project was extremely useful for comprehending the true nature of operating systems.
